# Киноцех личности

Сайт детской школы кино «Киноцех личности» (Краснодар) — неоновый редизайн.

Статический сайт без сборки: HTML + CSS + JavaScript. Чтобы посмотреть локально, достаточно открыть `index.html` в браузере.

## Структура

```
index.html          разметка и весь текст
css/style.css       стили, палитра и анимации
js/script.js        навигация, анимации, форма заявки
img/                фотографии наставников
render.yaml         конфигурация статического сайта для Render
```

## Палитра

Оттенки унаследованы от прежней версии сайта, но углублены и переведены в неон:

| Было | Стало |
| --- | --- |
| `#9ca755` олива | `#C9F23A` лайм |
| `#4E6851` зелёно-серый | `#4FE3A8` мята |
| `#DCC9A9` бежевый | `#FFC46B` неоновый песок |
| `#2D3047` тёмно-синий | `#070912`…`#1C2240` чернила (фон) |

Все цвета заданы CSS-переменными в начале `css/style.css` — менять оформление удобнее всего там.

## Форма заявки

Заявки отправляются через [Formspree](https://formspree.io) — адрес формы задан константой `FORMSPREE_URL` в начале `js/script.js`.

Прямая отправка в Telegram намеренно не используется: она требует токена бота прямо в клиентском коде, где его видит любой посетитель. Если нужны уведомления в Telegram, их подключают на стороне сервера либо средствами самого Formspree.

## Деплой

Хостится на Render как Static Site: без команды сборки, публикуемая директория — корень репозитория (см. `render.yaml`). Каждый push в `main` вызывает новый деплой.
